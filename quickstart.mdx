This guide gets a developer from a fresh clone to a running, testable API in a few minutes.

## Prerequisites

Before you begin, you must have:

- Python 3.x installed
- PostgreSQL installed and running
- Git installed

## Get started

<Steps>
  <Step title="Install">
    Clone the repository and set up a virtual environment.

    ```bash
        git clone <repository-url>
        cd backend
        python -m venv venv
        source venv/bin/activate
        pip install -r requirements.txt
    ```
  </Step>
  <Step title="Configure">
    Copy the example environment file and fill in your own values (database credentials, secret keys, etc.). Make sure PostgreSQL is running and the connection details match what's in your `.env` file.

    ```bash
        cp .env.example .env
    ```
  </Step>
  <Step title="Run it">
    Start the FastAPI server, then open the interactive API docs to inspect and test every registered endpoint.

    ```bash
        uvicorn main:app --reload
    ```

    Visit `http://localhost:8000/docs` to see it running.
  </Step>
</Steps>

  Need help? Open an issue in the project's GitHub repository.
